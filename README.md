# 🧒 Kids Learning Website

Kids Learning is a simple educational website designed for young children in Pre-Nursery, Nursery, and KG.

The website provides colorful and easy learning activities for alphabets, numbers, colors, shapes, and rhymes.

## ✨ Features

- ABC learning
- Number learning
- Color learning
- Shape learning
- Kids rhymes
- Audio learning
- Video rhymes
- Colorful child-friendly interface
- Simple navigation between learning pages

## 📚 Learning Sections

- 🔤 ABC
- 🔢 Numbers
- 🎨 Colors
- 🔺 Shapes
- 🎵 Rhymes

## 🛠️ Technologies Used

- HTML
- Basic CSS styling
- HTML Audio
- HTML Video

## 📁 Main Pages

- `website.html` - Home page
- `abc.html` - Alphabet learning
- `123.html` - Number learning
- `color.html` - Color learning
- `shapes.html` - Shape learning
- `rhyme.html` - Rhymes and videos

## 🚀 How to Run

1. Download or clone the repository.
2. Keep all HTML, audio, and video files in their correct locations.
3. Open `website.html` in your browser.
4. Select a learning section from the navigation menu.

## 🎯 Project Purpose

The purpose of this project is to create a simple and enjoyable learning environment where young children can learn basic concepts using text, colors, audio, and videos.
